# OGE LAB 2027

Интерактивный тренажёр ОГЭ по английскому языку.

## Разделы

- Грамматика — 75 вариантов, задания 20–28.
- Лексика — 75 вариантов, задания 29–34.
- Словообразование — 157 словарных семей, русские переводы и карточки.

Обе темы оформления (светлая и тёмная) и проверка ответов работают полностью на стороне браузера. Прогресс хранится в localStorage устройства ученика. Внешние библиотеки и CDN не используются.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000/.

## GitHub Pages

Для публикации перейдите в **Settings → Pages → Build and deployment → Deploy from a branch**, выберите **main**, папку **/(root)** и сохраните. После запуска публикации адрес: `https://zenner97.github.io/oge/`.

Внимание: некоторые исходные задания и ключи содержат опечатки или неполные фрагменты; материалы следует сверять с первоисточником.
