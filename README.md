# OGE LAB 2027

Интерактивный тренажёр подготовки к ОГЭ по английскому языку.

## Разделы

- **Грамматика** — 75 вариантов, задания № 20–28, проверка и открытие верных ответов.
- **Лексика** — 75 вариантов, задания № 29–34, проверка и открытие верных ответов.
- **Словообразование** — 157 словообразовательных семей, русские переводы, карточки и написание форм.

Дизайн: WordMaster-style — молочный фон, лаймовые акценты, контрастные контуры, иллюстрации; светлая и тёмная темы, мобильная адаптация. Выбор темы и ответы сохраняются локально в браузере; никаких логинов и серверной базы данных нет.

## Структура

```text
index.html          — HTML-разметка
assets/styles.css   — базовые компоненты и раскладка
assets/wordmaster.css — новый дизайн по референсу, светлая и тёмная темы
assets/interactions.css — крупный текст на десктопе и верхний выбор вариантов; анимации отключены
assets/data.js      — упражнения, ключи и переводы
assets/app.js       — проверка, карточки и навигация
assets/favicon.svg  — иконка вкладки
.nojekyll           — настройка GitHub Pages
```

Нет внешних CDN, сборщиков и npm-зависимостей: сайт работает на обычном статическом хостинге.

## Навигация и варианты

- Интерфейс работает без анимаций, ripple, конфетти и плавных переходов. Действия выполняются мгновенно.
- В грамматике и лексике выбор варианта доступен сверху и снизу; селекторы синхронизированы.
- На экранах ноутбуков/ПК текст упражнений крупнее.

## Озвучка слов

При нажатии на значок ▶ сайт **пытается** воспроизводить звук через открываемый браузером адрес Google Translate TTS (`translate.google.com/translate_tts`). Это **не документированный публичный API**, поэтому Google может блокировать его, ограничивать запросы, а в некоторых российских сетях адрес может быть недоступен.

Если ответ Google не получен, включается `speechSynthesis` браузера с приоритетом качественных английских голосов, если они установлены.

Для гарантированной нейросетевой озвучки на публичном сайте потребуется отдельный защищённый серверный API для **Google Cloud Text-to-Speech** с ключом в серверных переменных окружения и включённым биллингом. **Не добавляйте Google Cloud API-ключ в код сайта или GitHub-репозиторий.**

## Локальный запуск

Из корня репозитория выполните:

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000/ в браузере.

## GitHub Pages

В настройках репозитория: **Settings → Pages → Build and deployment → Deploy from a branch**, затем выберите ветку **main** и папку **/(root)**, сохраните изменения. После успешной публикации сайт будет доступен по адресу https://zenner97.github.io/oge/ .

> Важно: сам по себе коммит исходных файлов не включает GitHub Pages. Его нужно активировать в настройках репозитория.
